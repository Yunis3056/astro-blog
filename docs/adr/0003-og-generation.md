# ADR 0003: OG 图片在构建期生成并使用本地字体

## Status

Accepted

## Context

文章分享需要稳定的社交预览图。中文标题必须可读，构建过程不能依赖运行时服务或联网字体下载。

## Decision

OG 图片通过 `src/pages/og/[...slug].png.ts` 在构建期生成。

- 只为公开文章生成。
- 使用本地字体资源。
- 字体加载失败应在构建阶段暴露。
- 页面通过 `BaseHead.astro` 指向对应 OG 图片。

## Consequences

优点：

- 分享图可静态部署。
- 生产环境不需要图片生成服务。
- 中文渲染稳定，不依赖外部字体服务。

代价：

- 构建时间会随文章数量增长。
- 字体资源会增加依赖体积。
- 样式调整需要重新构建并抽查图片。
