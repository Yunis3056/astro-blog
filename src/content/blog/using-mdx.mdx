Astro 已经安装并启用了 `@astrojs/mdx`，所以这个站点可以同时使用 Markdown 和 MDX。普通文章用 Markdown 就够了，只有当文章需要组件时再使用 MDX。

## 什么时候用 MDX

MDX 适合这些场景：

- 在文章里复用现有组件。
- 插入可交互的小示例。
- 展示带样式的提示块或链接块。
- 把文章内容和组件展示放在同一个文件里维护。

如果只是普通文本、图片、代码块和表格，Markdown 更简单。

## 注意事项

MDX 可以渲染组件，但并不代表所有交互都会自动在浏览器中运行。如果引入的是需要客户端 JavaScript 的组件，仍然要按 Astro 的客户端指令规则处理。

这个示例先保留最小用法，确保内容集合、构建流程和路由都能正常工作。
